## ⭐ الميزات الرئيسية

### 🤖 نموذج التنبؤ الذكي

```
المكونات:
├─ Trend Component (الاتجاه) - 30%
├─ Attraction Component (الجذب نحو TP) - 20%
├─ Fractal Component (الفركتالات) - 15%
├─ Oscillation Component (التموج) - 20%
└─ RSI Component (قوة الاتجاه) - 15%

النتيجة: توقعات دقيقة بنسب ثقة واقعية

الدقة:
• الفترات الأولى (1-5): 75-85% ✅
• الفترات الوسطى (6-10): 65-75% ✅
• الفترات الطويلة (11+): 50-65% ⚠️
```

### ✨ تحليل الفركتالات

```
الكشف:
├─ Fractal High: نقطة عالية محاطة بنقاط أقل
├─ Fractal Low: نقطة منخفضة محاطة بنقاط أعلى
└─ نسبة القوة لكل فركتال

التطبيق:
├─ تحديد مستويات المقاومة والدعم
├─ كشف نقاط التحول المهمة
├─ تأكيد الأنماط الفنية
└─ تحسين دقة التنبؤات
```

### 📊 المؤشرات الفنية

```
المؤشرات المدمجة:
├─ Moving Average (MA20, MA50)
├─ Volatility (التقلبات)
├─ RSI (مؤشر القوة النسبية)
├─ Trend Direction (اتجاه السوق)
└─ Volume Analysis (تحليل الحجم)

التفسير:
├─ ثقة عالية (> 70%): إشارة قوية ✅
├─ ثقة متوسطة (50-70%): كن حذراً ⚠️
└─ ثقة منخفضة (< 50%): تجنب ❌
```

## 📊 معلومات الدقة

### دقة التنبؤ حسب الفترة الزمنية:

```
┌─────────────────┬──────────┬─────────────┐
│ نطاق الفترة     │ الدقة    │ الموثوقية   │
├─────────────────┼──────────┼─────────────┤
│ الفترات 1-3     │ 80-90%   │ عالية جداً  │
│ الفترات 4-7     │ 70-80%   │ عالية       │
│ الفترات 8-12    │ 60-75%   │ متوسطة      │
│ الفترات 13+     │ 45-60%   │ منخفضة      │
└─────────────────┴──────────┴─────────────┘
```

### عوامل تؤثر على الدقة:

```
✅ تحسّن الدقة:
├─ بيانات تاريخية طويلة (50+ شمعة)
├─ سوق مستقر (تقلبات منخفضة)
├─ اتجاه واضح (صاعد/هابط)
└─ فركتالات متعددة

❌ تقلل الدقة:
├─ بيانات قليلة (< 20 شمعة)
├─ تقلبات عالية جداً
├─ سوق محايد (تدرج جانبي)
├─ أخبار مفاجئة
└─ فركتالات قليلة جداً
```

## 💡 نصائح مهمة

### ✅ أفضل الممارسات:

```
1. استخدم فترات زمنية متوسطة
   └─ يومية أو ساعات (4-8 ساعات)

2. ركز على الثقة العالية
   └─ فقط > 70% للقرارات المهمة

3. ادمج مع مؤشرات أخرى
   └─ لا تعتمد على التنبؤ وحده

4. استخدم إدارة مخاطر صارمة
   └─ ضع SL و TP دائماً

5. راقب الفركتالات
   └─ فركتالات أكثر = إشارة أقوى
```

### ⚠️ التحذيرات:

```
❌ النموذج ليس تنبؤ مضمون 100%
❌ الأخبار المفاجئة قد تعطل التنبؤات
❌ الأسواق المضطربة أقل دقة
❌ الفترات الطويلة أقل موثوقية
❌ استخدم فقط مع إدارة مخاطر جيدة
```
